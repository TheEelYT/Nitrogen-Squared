# README artwork

`logo.png` is the project owner's original GIMP artwork, supplied and authorized
for public GitHub use. Its pixels are preserved from the supplied file.

The four 1280 × 720 screenshots document Nitrogen Squared's desktop presentation.
They were captured locally from the tested 0.1.1 runtime using the owner's verified
USA disc and disposable test cards. The title logo was temporarily hidden in the
private capture session as requested; the shipped game is unchanged. These are
documentation, not replacement game assets; N2O game imagery retains its original rights holders. No extracted game
icon or other standalone game resource is included.

The owner specifically requested these screenshots for the public README. This is
a narrow exception to the project's no-captures-in-Git rule. Other captures, RAM
traces, disc resources, generated game code, compiled games and saves stay private.

`configs/documentation_assets.json` pins the reviewed PNG hashes. The tracked-file
source audit accepts those exact documentation images separately. They are excluded
from the source allowlist and from both platform launcher packages. Keep them out
of setup artwork and runtime assets. GitHub's automatic repository source archives
include repository documentation, including these images.
