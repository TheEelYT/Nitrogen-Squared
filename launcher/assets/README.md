# Original launcher artwork

- `logo.png` is the exact owner-created GIMP N² logo, authorized for public GitHub use. Its pixels match `docs/images/logo.png`.
- `tunnel.png` is an original image generated for this project with OpenAI image generation on 2026-11-08. It depicts a faceted emerald/navy tunnel, cyan/violet energy rings and an original orange/gold craft. The prompt requested quiet dark space on the left for launcher controls and explicitly excluded text, interfaces and copied game assets.

Neither image comes from the commercial game dump. The ripped PS1 memory-card N icon is excluded. Exact SHA-256 values are reviewed in `configs/launcher_assets.json`; only these two PNG paths may enter launcher packages. The text-only source packer continues to exclude images.
